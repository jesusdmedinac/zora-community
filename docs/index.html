Zero-Trust · Local-First Architecture

Privacy Policy

Application: Zora Community Edition (Android & iOS)
Developer: Jesus Daniel Medina Cruz
Effective Date: November 16, 2026

1. Core Architectural Commitment: Local-First

Zora Community is an open-source, automotive diagnostic and maintenance copilot designed from the ground up around a Zero-Trust, Local-First privacy principle. We believe vehicle diagnostic data and telemetry belong strictly to the vehicle owner.

Unlike conventional telematics and automotive applications, Zora Community processes and stores your diagnostic logs, maintenance records, and copilot memory entirely on your local device (in an encrypted local SQLite database via SQLDelight). We do not operate central user tracking databases, we do not require third-party account registration for core features, and we never sell, monetize, or harvest personal identifiable information (PII).

2. On-Device AI Inference & Zero Token Leaks

Edge AI Execution Guarantee

On supported devices (such as Android devices equipped with Google AICore), Zora Copilot executes generative AI queries completely on-device via Google ML Kit GenAI Prompt API running on your device's Neural Processing Unit (NPU).

When you ask diagnostic or maintenance questions:

  • No audio or text prompts leave your phone: Inference is executed locally by Gemini Nano.
  • No cloud telemetry logging: Queries are never transmitted to remote server enclaves without explicit, per-session user consent.
  • Offline Fallback: When on-device neural hardware is unavailable, the application relies on an internal, deterministic rule-based heuristic engine with zero network dependencies.

3. Information Collected and Stored Locally

All data stored by the application remains under your complete control in your device's sandboxed storage:

  • Vehicle Profiles & Garage Context: Vehicle make, model, year, and technical configuration (e.g., engine type, recommended fluid specifications).
  • Diagnostic & Maintenance Prescriptions: Symptoms reported by the driver, local triage records, and maintenance logs (e.g., battery checks, fluid renewals).
  • Copilot Memory Slots: Ephemeral notes confirmed by the driver for garage reference (e.g., "Synthetic oil 0W-20 changed at 110,000 km"). These can be inspected and permanently deleted on-demand at any time from the Virtual Garage screen.
  • VIN Prefix Sanitation: If a Vehicle Identification Number (VIN) is entered for part fitment verification, the app applies an automated Zero-Trust sanitizer that strips unique serial components, retaining only the generic World Manufacturer Identifier and vehicle descriptor section (WMI/VDS prefix, e.g. 2HGFC2F5), preventing vehicle or driver re-identification.

4. Network Communications & Cloud AI Opt-In

Zora Community functions 100% offline. Network connectivity is exclusively utilized in the following explicit scenarios:

  • Explicit Cloud AI Opt-In: Fleet-wide crowdsourced part telemetry and live catalog verification are strictly disabled by default. Accessing these features requires driver acknowledgment through an explicit opt-in gate.
  • No Advertising ID (AD_ID): Zora Community does not request, access, or track the Android Advertising ID (com.google.android.gms.permission.AD_ID) or Apple Identifier for Advertisers (IDFA). The app contains zero commercial advertisement SDKs.
  • No Third-Party Analytics Trackers: We do not integrate tracking frameworks (such as Firebase Analytics, Adjust, AppsFlyer, or Facebook Pixel).

5. Device Permissions & Hardware Access

The application only requests device capabilities strictly necessary for driver interaction:

  • Microphone (Voice Mode): Audio input is captured strictly for live voice dictation and speech-to-text. Raw audio streams are never recorded to disk, uploaded to remote cloud repositories, or used for commercial profiling.
  • System Clipboard: Read and write access to clipboard is triggered solely when the driver taps the "Copy" action in the assistant action bar.

6. Data Retention, Export & Deletion

Because all data is stored on-device:

  • Immediate Deletion: You can purge individual memory entries directly in the Virtual Garage interface.
  • Complete Eradication: Clearing the application's data via Android/iOS system settings or uninstalling the app permanently erases all databases, logs, and telemetry vaults.

7. Children's Privacy

Zora Community does not knowingly address or collect personal information from children under the age of 13. The application is an automotive reference utility intended for vehicle drivers and maintenance operators.
